# Collezione Martina

Catalogo personale della mia collezione di carte Pokémon: foto fronte e retro, condizioni, valore stimato e acquisti.

## Cosa contiene

- `index.html`: la pagina del catalogo, con ricerca e filtri per serie, condizione, rarità e valore.
- `img/`: le foto di ogni carta (`-f` = fronte, `-b` = retro).

## Come aprirlo

Scarica il progetto e apri `index.html` con il browser.
